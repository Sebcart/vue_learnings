# Vue.js Learning Projects

A collection of small Vue 3 projects for learning and practicing Vue.js concepts.

## 📚 Projects

### 1. **blog**
Blog application with Vue 3 Composition API, Vue Router, and JSON Server.
- Composables for data fetching
- Post list and detail views
- Mock REST API

### 2. **hyrule-jobs**
TypeScript-based job listing application.
- Vue 3 with TypeScript
- Type definitions
- Job filtering and display

### 3. **jobs-routing**
Vue Router demonstration with nested routes.
- Job listings with routing
- Nested route structure
- 404 Not Found page
- JSON Server backend

### 4. **modal-project**
Modal component implementation.
- Reusable modal component
- Slot-based architecture
- Event handling

### 5. **reaction-timer**
Simple reaction time game.
- Interactive game mechanics
- Timer functionality
- Results component

### 6. **web-form**
Form handling and validation.
- Form components
- Input validation
- Vue form patterns

## 🚀 Quick Start

Each project has its own setup. Navigate to the project folder and:

```bash
cd [project-name]
npm install
npm run serve
```

For projects with JSON Server (blog, jobs-routing):
```bash
npx json-server --watch data/db.json --port 3000
```

## 🛠️ Tech Stack

- Vue 3
- Vue Router 4
- Composition API
- TypeScript (hyrule-jobs)
- JSON Server

## 📖 Learning Path

1. Start with **web-form** for basic Vue concepts
2. Try **modal-project** for component communication
3. Explore **reaction-timer** for reactivity
4. Learn routing with **jobs-routing**
5. Practice Composition API with **blog**
6. Add TypeScript with **hyrule-jobs**
